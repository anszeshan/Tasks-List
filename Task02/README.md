## Available Scripts
- `npm start`: Runs the app in development mode
- `npm run build`: Builds the app for production
- `npm test`: Runs the test suite

## How to Use
1. Fill out the "Add New User" form
2. Click "Add User" to create a new user
3. Use the table to view, edit, or delete users
4. Click the edit button to modify user details
5. Click the delete button (🗑️) to remove a user

## Validation
- Name: Minimum 2 characters
- Email: Must be a valid email format
- Age: Between 18 and 120
